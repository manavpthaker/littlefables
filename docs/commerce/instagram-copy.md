# Instagram — Copy Sheet

One block per image file. Paste-ready. Keep this open while posting.

Assets: `assets/social/instagram/` · Strategy and grid rationale: `instagram-launch.md`
· Voice rules: `positioning.md`

**Standing copy rule:** never write a caption that counts the styles. "Four styles,"
"six looks," "choose from" all read as a menu, which is the opposite of the claim.
The images show examples of range; the words must say where that range came from.

### Grid notes

- **Never post two Reels back to back.** Posts 7–9 are all three reels, which puts a
  band of three near-identical cream text cards across one row. It's the weakest part
  of the grid and it can't be fixed without deleting.
- **Desktop web is 4-wide, the app is 3-wide.** Most people see three. Don't
  over-engineer around a layout half your visitors won't see.
- **The bed/tablet post is still live and still broken** — reader text clipped
  mid-sentence. `20-real-kid-parent` is already up, so replace it with
  `19-coloring-page` or just delete.
