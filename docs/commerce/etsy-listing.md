# Etsy Listing

Everything needed to create the listing. Paste-ready.

## Listing type — read this first

Etsy forces a choice: **Physical item** or **Digital file**. Neither fits a made-to-order
digital product cleanly.

**Use: Digital file.** Etsy auto-delivers whatever file you upload the instant payment
clears. That instant download is *not* the book — it's a **welcome PDF** containing:

1. "Here's what happens next" — the 24h preview promise
2. The Typeform intake link
3. What to expect at each stage
4. Contact info

The real book arrives later via Etsy message + email. This is the standard pattern
custom-portrait and custom-illustration sellers use, and it works in our favour: the
buyer gets something immediately (reduces post-purchase anxiety) and the intake link
is delivered without depending on them reading the confirmation email.

**Do not** use a Physical listing with free shipping to get processing-time fields.
That risks Etsy policy trouble.

## Personalization field

Etsy allows up to 5 structured fields. Configure:

**Field 1 — Text, required**
> Instruction (256 char limit):
> ```
> Your child's first name, as you'd like it to appear in the book. We'll email you a
> short questionnaire right after checkout for everything else — their age, what they
> love, and the art style you want.
> ```

**Field 2 — Dropdown, required**
> Label: `Child's age`
> Options: `3–4` · `5–6` · `7–8` · `9+`

**Field 3 — Text, optional**
> Instruction:
> ```
> Any deadline we should know about? (Birthday, gift date, Christmas.) Leave blank if
> there's no rush.
> ```

**Field 4 — Dropdown, optional**
> Label: `Is this a gift?`
> Options: `Yes — send me a gift certificate` · `No — it's for my own child`

Everything else is collected in the Typeform. Keep the Etsy fields minimal — every
required field on Etsy is a conversion drag.

## Instant-download file

Upload a single PDF named `Little-Fables-Welcome.pdf` containing:

1. **Header** — the tree mark + "Little Fables" wordmark
2. **"Thank you — here's what happens next"**
3. **Step 1** — Big terracotta/oxblood button: "Tell us about your kid" → Typeform link
4. **Step 2** — "We'll send style previews within 24 hours"
5. **Step 3** — "Your book arrives 3–4 days after you approve"
6. **Footer** — contact email, mention of the unlimited-revisions guarantee

One page. Warm, not corporate. Blocked on the Heritage DS for visual treatment.

## Processing time

Set to **1–3 business days**. This covers the preview stage. The listing description
carries the full two-stage explanation. Do not set it longer — Etsy surfaces
processing time in search filters and longer times suppress impressions.

## SEO notes

- Etsy weights **title front-load** heavily — first 3–4 words matter most
- Tags should not duplicate title words exactly; use variants to widen the net
- Update tags seasonally (see Tags section)
- The description's first 160 chars are the Google snippet — they're written above to
  work standalone
- Reviews are the real ranking moat. New shops with under 50 reviews get buried
  regardless of listing quality. See [`email-templates.md`](email-templates.md) for
  the review flywheel.

## Etsy economics

On a $29 sale:

| Line | Amount |
|---|---|
| Listing fee | $0.20 |
| Transaction fee (6.5%) | $1.89 |
| Payment processing (3% + $0.25) | $1.12 |
| **Total fees** | **$3.21** |
| **Net** | **$25.79** (~89%) |

Offsite Ads are pay-on-sale at ~15% and become non-optional above $10k/12mo. Onsite
Etsy Ads run $0.10–$1.50 CPC, averaging $0.25–$0.50; competitive gift niches push
$0.50–$1.00+. Model breakeven at ~$0.60 CPC and 2–4% conversion.
