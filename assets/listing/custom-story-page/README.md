# Custom Story Page Assets

Assets for the custom storybook listing page.

## Every Book Is Illustrated To Order

Section eyebrow: `six worlds to choose from`

Section H2: `Every book is illustrated to order`

Section body:

```text
Pick the style when you order - the one that fits your child, or the one that fits the moment. We paint every book by hand in the style you choose.
```

Layout: six samples in a 3-column x 2-row grid on desktop, with `min-column-width: 220px`. Stack the figures on mobile.
