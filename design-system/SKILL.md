If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Hard rules that define this brand: aged-ivory paper (#EDE3CE, never white), walnut ink (#2A1D12), oxblood (#7D2E2B) as the only action color; IM Fell English + EB Garamond + IM Fell English SC (no sans-serif, no handwriting, ever); no emoji; ornament with restraint (fleuron/double-rule/filigree/sunburst/rule-and-dot/dropcap); mechanical music-box motion (200/600/1200/1800/3200ms); mercy is brass, never red; numerals written out on kid surfaces; three densities via data-density (kid default, parent, outward); bedtime dark-walnut is kid-only.
